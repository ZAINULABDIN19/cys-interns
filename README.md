## Glossary of 20 Cybersecurity Terms

1. Threat – Anything that can cause harm to a system.
2. Vulnerability – A weakness that can be exploited.
3. Risk – The chance of loss due to a threat.
4. Exploit – A method used to take advantage of a vulnerability.
5. Malware – Malicious software designed to damage systems.
6. Firewall – A security system that filters network traffic.
7. Antivirus – Software that detects and removes malware.
8. Phishing – A fake message used to steal information.
9. Encryption – Converting data into a secure format.
10. Decryption – Converting encrypted data back to normal.
11. Authentication – Verifying a user's identity.
12. Authorization – Giving permission to access resources.
13. VPN – A secure private network over the internet.
14. IDS – Intrusion Detection System.
15. IPS – Intrusion Prevention System.
16. Patch – A software update that fixes security issues.
17. Brute Force Attack – Trying many passwords until one works.
18. Social Engineering – Manipulating people to obtain information.
19. Penetration Testing – Authorized security testing of a system.
20. Zero-Day Vulnerability – A newly discovered vulnerability with no available fix.
